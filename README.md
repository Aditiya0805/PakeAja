# PAKEAJA

Aplikasi rekomendasi outfit harian berbasis Flutter + Firebase.

> **"Bingung mau pake apa? PakeAja."**

PakeAja membantu kamu menentukan outfit berdasarkan pakaian yang sudah kamu miliki. Fokus utama: memaksimalkan pakaian yang ada, bukan membeli yang baru.

## Fitur Utama

- Register / Login (Email + Google Sign-In)
- Forgot Password
- Lemari digital (kamera/galeri, crop, compress)
- Kategorisasi pakaian (kategori, warna, gaya, cuaca)
- Rekomendasi outfit rule-based (sesuai acara, warna, sepatu, rotasi)
- Acak ulang rekomendasi
- Simpan outfit favorit
- Catat outfit yang dipakai + riwayat
- Profil + statistik
- Offline cache (Firestore persistence)

## Tech Stack

- Flutter + Dart (null safety)
- Firebase: Auth, Firestore, Storage
- Riverpod (state management)
- go_router (routing)
- image_picker, image_cropper, flutter_image_compress
- cached_network_image, permission_handler

## Setup Firebase

### 1. Buat Project Firebase

1. Buka [Firebase Console](https://console.firebase.google.com/)
2. Klik **Add project** → beri nama `pakeaja`
3. Aktifkan **Google Analytics** (opsional)

### 2. Install Firebase CLI & FlutterFire

```bash
# Install Firebase CLI (kalau belum)
npm install -g firebase-tools
firebase login

# Install FlutterFire CLI
dart pub global activate flutterfire_cli
```

### 3. Tambahkan App Android

1. Firebase Console → Project settings → **Add app** → Android
2. Package name: `com.example.pakeaja` (atau sesuai `applicationId` di `android/app/build.gradle`)
3. Download `google-services.json` → letakkan di `android/app/google-services.json`

### 4. Tambahkan App iOS

1. Firebase Console → **Add app** → iOS
2. Bundle ID: `com.example.pakeaja` (atau sesuai `PRODUCT_BUNDLE_IDENTIFIER` di Xcode)
3. Download `GoogleService-Info.plist` → letakkan di `ios/Runner/GoogleService-Info.plist`

### 5. Jalankan flutterfire configure

Di root project:

```bash
flutterfire configure
```

Perintah ini akan:
- Membuat `lib/firebase_options.dart` otomatis (menimpa placeholder)
- Mengaktifkan Auth, Firestore, Storage

### 6. Aktifkan Metode Login

Firebase Console → Authentication → Sign-in method:
- ✅ Email/Password
- ✅ Google

Untuk Google Sign-In di Android: tambahkan SHA-1 (debug) via:
```bash
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
```
Masukkan SHA-1 ke Firebase Console → Project settings → Android app → Add fingerprint.

### 7. Deploy Security Rules

```bash
# Install Firebase CLI (kalau belum) dan login
firebase init firestore   # pilih project, file firestore.rules
firebase init storage     # pilih project, file storage.rules

# Deploy
firebase deploy --only firestore:rules
firebase deploy --only storage:rules
```

Atau copy-paste manual:
- Firestore: Console → Firestore → Rules → paste isi `firestore.rules`
- Storage: Console → Storage → Rules → paste isi `storage.rules`

### 8. Aktifkan Firestore Offline Persistence

Offline persistence aktif secara default di Android/iOS (native SDK). Tidak perlu kode tambahan.

## Algoritma Rekomendasi

Rule-based (tanpa ML). Scoring per item:

| Faktor | Bobot | Keterangan |
|--------|-------|------------|
| Kesesuaian acara | 40 | Style pakaian sesuai occasion |
| Kesesuaian warna | 25 | Warna netral/analogus dapat score tinggi |
| Kesesuaian sepatu | 15 | Loafers/pantofel untuk formal, sneakers untuk casual |
| Rotasi pemakaian | 20 | Item lama tidak dipakai diprioritaskan |

Kombinasi minimal: **(1 atasan + 1 bawahan + 1 sepatu)** atau **(1 one-piece + 1 sepatu)**.
